# Template utilities sit in the site's utilities layer

- Status: accepted, 30 September 2026, pending the owner's check
- Date: 30 September 2026
- Amends: `templates/tailwind.css` (how the templates' utilities are emitted)

## Context

The templates' utilities are generated by their own stylesheet, `templates/tailwind.css`, so the pipeline's pages carry only what the templates use. That stylesheet emitted them unlayered. Unlayered rules beat every layered rule whatever their specificity, and the site's own utilities (from `app/globals.css`) are in Tailwind's `utilities` layer. So on a preview a template's `sr-only` beat the site's `focus:not-sr-only` on the skip link, and the skip link stayed a one-pixel square when a keyboard user focused it. Found during the Intaglio build of 28 September 2026 and kept when that build was deleted, because it touches every preview and no template.

## Decision

The templates' utilities are imported into the `utilities` layer (`@import 'tailwindcss/utilities.css' layer(utilities) source('.')`), with an `@layer theme, base, components, utilities;` statement first so the order holds whichever sheet loads first. In the layer they are weighed by specificity and order like the site's own, and the focus variant wins.

## Consequences

- The skip link shows on focus on every preview.
- A template's own unlayered stylesheet now beats a utility on the same element whatever the specificity, and an `!important` utility beats an unlayered `!important` rule. A pixel and computed-style diff of the eight example routes before and after found no change (28 September 2026); Inegro (ADR 0041), written after, relies on neither.
