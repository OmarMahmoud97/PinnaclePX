# Record architecture decisions

- Status: accepted
- Date: 2026-09-02

## Context

A solo-maintained project still benefits from a written trail of why the structure looks the way it does, so future changes are made against stated reasoning rather than guesswork.

## Decision

Record architecture decisions as Markdown files in `docs/adr/`, numbered sequentially, using the MADR format (context, decision, consequences).

## Consequences

Each significant structural or tooling change adds or supersedes an ADR. The standards document at `docs/standards.md` remains the primary reference; ADRs capture deviations and later decisions.
